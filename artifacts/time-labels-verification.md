# 表格时间标注排查

旧页面默认在括号中显示区间配速。配速使用分:秒/km，不能与发枪时间相加。相同的冒号格式容易让读者误认为括号内是到站钟点。

新版默认显示到站钟点。括号明确标注「发枪」「到站」「完赛」。切换到配速时，括号明确标注「配速」或「等效配速」，并保留 `/km` 单位。

主数字为累计出站耗时，包含本站停留。到站钟点使用到站耗时计算。停站时另列到站耗时和停留分钟。

网页与 SVG/PNG 共用时间标注模块。分钟边界使用相同的取整规则。缓存按资源版本匹配，避免网页与导出器混用不同版本。

验证结果：

- 06:00 发枪，12 小时方案的终点显示 `12:00（完赛 18:00）`。
- CP1 停留 5 分钟时，目标方案显示出站耗时 `01:49`，到站钟点 `07:44`，到站耗时 `01:44`。
- 23:30 发枪，12 小时方案的终点显示 `12:00（完赛 次日 11:30）`。
- 配速模式明确显示 `配速 10:00/km`。
- 390 px 手机视口下，页面宽度保持 390 px，表格独立横向滚动。
- 12 项 Python 测试、17 项算法对照、4 项时间标注和 2 项缓存测试均通过。

浏览器使用 ego-browser 验证，已从公网下载 PNG 并检查标注。
